# PCT Brantford Website Redesign

A responsive React + Vite redesign prototype for Personal Computer Terminal (PCT) Brantford, styled with Chakra UI.

## Run locally

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```

## Included
- Modern responsive homepage
- Original repair-workshop hero photography (`assets/pct-repair-workshop.png`)
- Service cards
- Repair workflow
- About / trust section
- Store / product section
- FAQ accordion
- Repair request form UI
- Mobile navigation
- React-managed repair-form confirmation state
- Chakra UI theme tokens and responsive component styling (no standalone stylesheet)
- Click-to-call and email links
- Google Maps directions link

## Before launch
1. Replace the demo PCT mark with the official PCT logo.
2. Replace the generated hero image with approved PCT photography if preferred.
3. Replace the review placeholder with verified Google reviews.
4. Connect the repair form to Wix Forms, Formspree, Netlify Forms, or a backend.
5. Confirm current service descriptions, hours, pricing, warranty and turnaround claims.
6. Add real Store inventory and checkout if ecommerce is required.
7. Add Google Analytics/Search Console and local SEO metadata.
